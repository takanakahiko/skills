---
name: review-branch-diff
description: ブランチの作業内容をレビューする
allowed-tools: Read, Grep, Bash(git log *), Bash(git diff *)
---

現在のブランチの作業内容を批判的にレビューして。

差分は、branchのbase branchからのものを参照して、それをレビュー対象にして。
このブランチの作業内容外のものは指摘しないで。
base branchはmainやmasterとは限らないで、ネストしたブランチの可能性もあります。

各指摘は、実際にコードを読んで事実確認してから報告して。
推測や未検証の指摘は含めないこと。
可能であればローカルでサービスを実行して動作確認し、指摘の裏付けを取ること。

指摘はカテゴリ別に整理して：
- セキュリティ
- バグ・不具合
- アーキテクチャ・設計
- パフォーマンス
